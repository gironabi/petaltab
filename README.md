# PetalTab ꕤ

A customizable Windows desktop app for keeping notes and to-dos within reach.

## Features

- Separate tabs for a checklist and free-form notes with formatting
- Custom colors, fonts, and window transparency
- An always-on-top pin
- A draggable ꕤ tab that stays at the edge of your screen when the app is tucked away
- Notes, tasks, and preferences saved locally

## Run from source

Open the project folder in PowerShell and run:

```powershell
npm.cmd ci
npm.cmd start
```

Built with Electron, JavaScript, HTML, and CSS.
